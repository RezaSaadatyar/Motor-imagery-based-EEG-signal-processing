# Deep Learning for Motor Imagery Decoding

**Status:** Planned — no new models have been trained in this subproject.

## Research question

Under controlled data splits and fair evaluation, how do deep learning methods for EEG motor imagery compare with established classical decoding baselines?

## Candidate approaches

Temporal/spatial convolutional networks, EEGNet-style models, shallow and deep ConvNets, and attention-based architectures where justified by data quantity and compute. Architecture selection and claims of improvement must be evidence-led.

## Data and evaluation

Dataset availability, participant identity, labels, sampling characteristics and usage conditions must be verified before implementation. Comparisons should respect identical splits, training-only fitting, suitable hyperparameter searches, class balance and computational budgets.

## Intended outputs

Numbered learning notebooks, study-specific model code, training diagnostics, controlled benchmark results and scientific discussion of limitations. All are planned.

## Next stage

Select an adequate dataset and a minimal, defensible neural baseline; specify the training protocol and resource requirements.
