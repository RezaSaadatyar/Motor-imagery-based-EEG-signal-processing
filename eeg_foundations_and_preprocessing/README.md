# EEG Foundations, Signal Processing and Motor Imagery Analysis

**Status:** Initial planning and scaffolding; no new experiments have been executed.

## Research aim

Build a structured, beginner-accessible and scientifically rigorous introduction to EEG-based motor imagery (MI), from signal acquisition concepts and dataset understanding to temporal/spatial preprocessing and exploratory analysis.

## Planned scope

- Fundamentals of EEG, motor imagery, BCI paradigms, sensor locations, mu/beta rhythms and event-related desynchronisation/synchronisation (ERD/ERS).
- Dataset inspection, channel metadata, event annotations, trial boundaries and signal visualisation.
- Time-domain, frequency-domain and time-frequency analysis.
- Temporal filtering, referencing, surface Laplacian and artifact-handling methods, with explicit assumptions and potential signal distortion.
- Reproducible preprocessing comparisons and a clearly specified evaluation protocol.

## Existing materials

The repository already contains historical material under [`Code/`](../Code/), [`Data/`](../Data/) and [`PDF/`](../PDF/). **These remain unchanged.** Dataset metadata, labels, file provenance and licence conditions must be checked before deriving new experimental claims. Relevant legacy algorithms may be referenced or copied into new code only after a separate, specific approval.

## Intended outputs

Numbered explanatory notebooks, reusable study-specific Python modules, scientific visualisations, and evidence-based methodological documentation. These are **planned outputs**, not completed implementations.
