# Cross-Subject Generalisation and Transfer Learning

**Status:** Planned — feasibility depends on verified multi-participant recordings.

## Research question

How robustly can EEG motor imagery decoders generalise across participants and sessions, and when do adaptation techniques provide measurable benefits?

## Candidate approaches

Subject-dependent versus subject-independent evaluation, leave-one-subject-out protocols, session transfer, normalisation and alignment, fine-tuning and carefully selected domain adaptation approaches.

## Data and evaluation

A suitable dataset must contain the required participant/session structure. Participant and session independence, calibration budgets and leakage prevention are central requirements. No transfer-learning performance claims are made at this stage.

## Intended outputs

Clearly specified evaluation protocols, baselines, reproducible experiments, between-subject analysis and a transparent limitations report.

## Next stage

Validate available participant and session metadata, then approve one generalisation question and one baseline protocol.
